10  ·  How it's built

The temporal AI stack.

Real dataset. Small, runnable model. Bounded compute.

01 · Data
TimeNet + Backblaze
Public HDD telemetry, verified pipeline
  • 3,000 drives · ST8000NM0055
  • 547,812 daily observations, Jul–Dec 2024
  • 13,616 TimeNet signal-description tasks
  • Disjoint splits by drive-hash; ordered cutoffs
  • Checksums pinned; causal windows tested
02 · Model
OpenTSLM-SP on Gemma 3 270M
Time-series language model, runnable
  • Base LM frozen; encoder + projector adapted
  • Small enough to run on-prem — no vendor lock-in
  • Weights & revisions pinned in config/model.yaml
  • Weak SMART labels — kept honest, not oversold
03 · Compute
Nebius GPU, $600 cap
Bounded training, resumable jobs
  • Every run: pre-declared budget & stop conditions
  • Atomic checkpoints, tested resume
  • Held-out test partition, never tuned on
  • Baseline comparison mandatory
